## Abstract / Core Idea
The present research introduces an evolutionary algorithm able to procedurally generate dungeon maps con - taining locked door missions. The evolutionary algorithm evolves a tree structure, which encodes dungeons, aiming to generate levels close to the input configuration provided by a game designer. The tree structure holds information about the number of rooms, connections between them, and their position within a 2D map. The proposed encoding also allows evolving semantic information about the narrative of the game. This is done by feasibly setting keys and locks throughout the dungeons for locked door missions. The generated dungeons are then evaluated computationally and as a proof of concept using an adventure game prototype. A total of 70 players evaluated the contents and the results show that the procedurally generated levels are perceived as more human-made, fun, and difficult than their human-made counterparts for most cases.

## Conclusion / Findings
The research presented in this paper introduces the CEA as a PCG method able to generate dungeon maps and locked-door missions simultaneously. Based on the results reported, we addressed the following research question: Is it possible to generate content for mission and levels without complex constraints and loss of quality in the pro - cess? The question was addressed once we generated such content using a single EA that spent less than a minute for most cases and demands only a few numerical inputs. There is no need for creating a strict set of rules (such as grammars and their rules or sets of constraints), and the method is validated from computational tests and feedback from players through a game prototype. CEA represents the dungeon map as a tree structure, where each node was a room and each edge the connection between rooms. The rooms could belong to three different types: normal, key (which contained a key inside it), and locked (meaning the edge between it and its parent was locked). We also applied two different path-finding algorithms (A* and DFS) to measure the explo - ration of the generated dungeon and to add this parameter in the fitness function. The algorithm was able to create levels that both matched the designer ’ s inputs and placed the special rooms in a way that leads the player to explore the whole level to find the exit.
